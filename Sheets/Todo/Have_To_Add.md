## Legend & Instructions

### DIFFICULTY SCALE

- **Easy (★☆☆)**: Beginner-friendly to foundation-level problems — core syntax and minor logical thinking
- **Medium (★★☆)**: Standard interview-level — requires pattern knowledge
- **Hard (★★★)**: Multi-concept to FAANG-level — optimised approach and advanced techniques required

### COURSE PHASES

- **Phase 1**: Fundamentals & Linear DS - Arrays, 2D Arrays, Math, Strings
- **Phase 2**: Searching - Binary Search
- **Phase 3**: Algorithmic Thinking - Recursion, Sorting
- **Phase 4**: OOP Concepts - OOPS
- **Phase 5**: Advanced Linear DS - Linked List, Stacks, Queues
- **Phase 6**: Hierarchical DS - Binary Trees, BST, Tries
- **Phase 7**: Core DS & Techniques - Hashmaps, Heaps, Prefix Sum, Sliding Window, Bit Manipulation
- **Phase 8**: Standard Algorithms - Greedy, Graphs
- **Phase 9**: Exhaustive Search & Optimisation - Backtracking, Dynamic Programming

### PLACEMENT RULES APPLIED

- **Dependency Rule**: Multi-concept problems are placed under the topic that appears LATER in the course
